# Brief: convert past-paper free-response parts to structured, auto-checked answers

Context: `PAST_BRIEF.md` (how the past papers were transcribed) and `app/src/types.ts` (read `Question`, `OpenQ`, `ShortQ`, `Blank`, `OrderQ`, `WidgetQ`, `Tasks`, `QIndo`). You edit ONLY the paper file(s) named in your task (`app/src/practice/bank/past/pYYYY.ts`). Typecheck with `cd app && npx tsc -b` (ignore errors in files you don't own). No dev server.

## Goal
Every `kind: 'open'` part is currently self-graded. Convert it to the lightest input that can check it automatically, keeping friction low and accepting every valid answer. Keep `id`, `lecture`, `topic`, `source`, `past`, `difficulty`, `hints`, `work`, `explanation`, `indo` (update `indo` as below). Remove fields that no longer belong to the new kind (e.g. `answer: string` when it becomes `short`; put any model-answer wording that isn't already in `explanation` into `explanation`).

Pick per part:
1. **`short`**: one or a few typed blanks (`blanks: Blank[]`). Use for: Z / group / period; the four quantum numbers (one blank each: `n`, `l`, `mₗ`, `mₛ`, with `accept` listing every valid value, e.g. mₛ `['+1/2','-1/2','1/2','+½','-½','½']`, mₗ any allowed value if the question allows any); an electron configuration (`type: 'config'`, one accept is enough, the checker expands cores and ignores order; give exception configs as the real one); a formula/ion (`type: 'formula'`); a reaction equation such as an ionisation step (`type: 'equation'`, e.g. `'Se^3+(g) -> Se^4+(g) + e^-'`); a name or one-word property (`type: 'text'`, list synonyms: `['trigonal pyramidal','trigonal pyramid']`, Indonesian too: `['piramida trigonal', ...]`); a number with unit (`type: 'number'`, `accept: ['120']`, `unit: '°'`, `tol`). Add `wrong` entries for the classic mistakes (e.g. config `match` of the neutral atom when the question is about the ion → `msg: 'That is the neutral atom: remove electrons for the 2+ charge, from the highest n first.'`). Labels short and bilingual via `indo.labels` (same order as `blanks`).
2. **`order`**: any "rank / urutkan / order" part. `items` (display strings, unicode formulas ok: 'Na⁺', 'O²⁻'), `answer` = indexes first→last in the direction the question asks, `ends` e.g. `['smallest', 'largest']` (+ `indo.items` only if item text differs, `indo.ends` e.g. `['terkecil', 'terbesar']`). Use `ties` for genuinely equal items.
3. **`widget`**: draw-a-structure parts where the species is EXACTLY in the workbench lists below: `{ kind: 'widget', widget: 'lewis', task: { species: 'NO3^-' } }` (the Lewis workbench checks electrons, octets, formal charges and best structure; add `resonance: true` if the part asks for resonance forms); `widget: 'vsepr'` for shape/angle/domain questions; `widget: 'econfig'` `{ element: 'Fe', charge: 2 }` for orbital diagrams/box notation; `widget: 'mo'` for MO diagrams. If the part asks for more than the workbench checks (e.g. "draw + explain"), split it: widget part + a `short`/`open` part, with labels like `4a(i)`, `4a(ii)` and new unique ids.
   - Lewis species: N2F2 SiF4 H2CO3 PCl5 BBr3 CO2 H2SO4 NO3^- CO3^2- NCO^- HClO4 XeF4 I3^- BrF5 TeF4 SF4 ClF3 XeF2 SF6 SF4O XeF4O ICl5 BF3 BCl3 BeCl2 BeH2 H2O NH3 CH4 H2S OF2 OCl2 PF5 SO2 SO3 SO4^2- NO2^- O3 NH4^+ H3O^+ PO4^3- ClO4^- HCOO^- HNO3 H2CO HCN N2 O2 F2 NO CN^- CO OCl^- CH3OH C2H4 C2H2 C2H6 N2O
   - VSEPR species: BeH2 BeCl2 CO2 HCN NCO^- N2 BF3 BCl3 BBr3 BClF2 SO3 NO3^- CO3^2- H2CO C2H4 SO2 O3 CH4 CCl4 SiF4 CH2Cl2 CHCl3 NH4^+ SO4^2- NH3 H2O H2S OF2 OCl2 ClF2^+ HCl PCl5 PF5 SF4O SF4 SeF4 TeF4 ClF3 XeF2 I3^- SF6 BrF5 IF5 ICl5 XeF4O XeF4 ICl4^- C2H2
   - MO species: homonuclear/heteronuclear diatomics of period 1–2 incl. ions, e.g. "O2^-", "NO^+", "CN^-".
4. **Keep `open`** for explanations, multi-structure drawings of species not in the lists (e.g. N₂O₂²⁻, N₂O₅), or anything a checker can't judge fairly. Every remaining `open` part MUST get a `rubric`: 2–5 short, independently checkable key points (each one a fact the answer must contain, e.g. "States LiF is ionic", "Small ions + high charge density → large lattice energy", "Lewis structure has 24 valence e⁻"), plus `indo.rubric` in the same order.

Rules: chemistry correctness first; never make the checker stricter than the question (accept every correct form and spelling variant, including Indonesian words); keep hints/work valid for the new format. The workbench parts show the stem above the workbench, so the stem must still say what to do.

## Final report (≤ 120 words)
Per file: how many parts became short / order / widget / stayed open (with rubric), any splits (new ids), anything you were unsure about.
